# Aurora — AI Print Assistant для STE Slicer

> Интеллектуальный плагин для слайсера STE Slicer (Stereotech).  
> LLM автоматически подбирает параметры FDM 3D/5D-печати, анализирует STL-геометрию, строит тепловую карту напряжений и запускает слайсинг.

---

## Установка

### Шаг 1 — Зависимости Python

```bash
pip install -r requirements.txt
```

Требуемые пакеты: `openai`, `trimesh`, `numpy`, `PyQt6`, `python-dotenv`, `requests`, `pydantic`.

### Шаг 2 — Файл конфигурации `.env`

Скопируйте `.env.example` в `.env` и заполните:

```env
LLM_API_URL=https://665dc1hack2026.k8s.stereotech.cloud/v1
LLM_API_KEY=ВАШ_КЛЮЧ_СЮДА
LLM_MODEL_NAME=gpt-4o
```

> Ключ выдан организаторами хакатона. URL указывает на прокси-сервер Stereotech.

### Шаг 3 — Установка в STE Slicer

1. Скопируйте папку `plugin/` в директорию плагинов STE Slicer:
   ```
   C:\Program Files\STE Slicer\plugins\AuroraAI\
   ```
   Итоговый путь должен выглядеть так:
   ```
   C:\Program Files\STE Slicer\plugins\AuroraAI\__init__.py
   C:\Program Files\STE Slicer\plugins\AuroraAI\.env
   ...
   ```

2. Положите `.env` рядом с `__init__.py` (внутри `AuroraAI\`).

3. Перезапустите STE Slicer.

4. Панель **Aurora — AI Print Assistant** появится как боковой виджет.

## Проверка работоспособности (без STE Slicer)

### Быстрый тест всех модулей

```bash
python test_standalone.py
```

Что проверяется:
- ✅ Загрузка конфига из `.env`
- ✅ GeometryAnalyzer (анализ нависаний, рекомендация 3D/5D)

## Как пользоваться плагином

### Базовый сценарий

1. Запустите STE Slicer — панель Aurora откроется автоматически справа.
2. Введите задачу в поле ввода, например:
   ```
   Кронштейн под нагрузку 50 кг. Материал PETG. Без поддержек.
   ```
3. Нажмите **▶ Отправить** (или `Enter`).
4. Агент Aurora:
   - Покажет бейджи выполняемых инструментов в реальном времени
   - Проанализирует геометрию и нагрузки
   - Подберёт параметры и установит их в слайсере
   - Запустит слайсинг
   - Объяснит каждое принятое решение

### С прикреплённым STL-файлом

1. Нажмите **📎 Прикрепить файл** → выберите `.stl` файл.
2. Введите описание задачи и нажмите **▶ Отправить**.
3. Агент автоматически вызовет анализ геометрии и (при упоминании нагрузки) FEA анализ.

### С фотографией детали

1. Нажмите **📎 Прикрепить файл** → выберите `.jpg` / `.png`.
2. Опишите задачу — агент увидит изображение и учтёт визуальные характеристики детали.

## Примеры запросов

| Запрос | Что сделает агент |
|--------|-------------------|
| `Декоративная ваза. PLA, быстрая печать.` | 3D-режим, PLA 210°C, инфилл 15%, поддержки выкл. |
| `Кронштейн под нагрузку 50 кг. PETG.` | FEA анализ → адаптивный инфилл → 5D если нависания → PETG 240°C |
| `Шестерня для мотора. Нейлон, максимальная прочность.` | Nylon 260°C, инфилл 60–80%, 5D-режим |
| `Гибкий уплотнитель. TPU.` | TPU 230°C, инфилл 20%, медленная скорость |

## Киллер-фича: FEA Тепловая карта напряжений 🌡️

При упоминании **нагрузки, прочности, кронштейна** агент запускает [`StressAnalyzer`](plugin/mcp_tools/stress_analyzer.py):

1. Каждый треугольник меша получает стресс-скор:
   - 70% — совпадение нормали с вектором нагрузки (зоны растяжения/сжатия)
   - 30% — локальная кривизна (концентраторы напряжений)
2. Зоны классифицируются:
   - 🔴 **Красные** — высокое напряжение → инфилл **80%**
   - 🟡 **Жёлтые** — среднее → **40%**
   - 🟢 **Зелёные** — низкое → **15%**
3. Строится Z-профиль адаптивного заполнения.
4. Рекомендуется оптимальная ориентация (слои вдоль вектора нагрузки).
5. Результат: **~40% экономии материала** при максимальной прочности детали.

## Решение проблем

| Проблема | Решение |
|----------|---------|
| `ModuleNotFoundError: trimesh` | `pip install trimesh numpy` |
| `ModuleNotFoundError: openai` | `pip install openai` |
| `API key not found` | Проверьте файл `.env` рядом с `__init__.py` |
| Панель не появляется в STE Slicer | Убедитесь что путь `plugins\AuroraAI\__init__.py` корректен |
| Агент не отвечает | Проверьте `LLM_API_URL` и доступность сети |
| `trimesh` fallback данные | STL-файл не найден — передайте корректный путь |

## Технологии

- **LLM**: OpenAI-compatible API (GPT-4o / любая совместимая модель)
- **Function Calling / MCP**: 9 инструментов для управления слайсером
- **FEA**: trimesh + numpy (стресс-прокси по нормалям и кривизне)
- **UI**: PyQt6 (встроен в Cura/STE Slicer framework)
- **Async**: QThread — UI никогда не замерзает
