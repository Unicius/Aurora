# AI Assistant plugin for STE Slicer — Team Aurora

Интеллектуальный плагин для слайсера STE Slicer (Stereotech), обеспечивающий автоподбор параметров FDM 3D/5D-печати на базе LLM и MCP-инструментов.

## Установка и запуск

1. Скопируйте папку \plugin\ в директорию плагинов STE Slicer:
   \\\	ext
   C:\Program Files\STE Slicer\plugins\
   \\\
2. Создайте файл \.env\ в корне плагина на основе \.env.example\ и укажите ваш API-ключ и URL доступа к LLM.
3. Перезапустите STE Slicer. Окно чат-бота отобразится в интерфейсе программы.
